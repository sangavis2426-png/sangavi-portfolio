SANGAVI S - PORTFOLIO WEBSITE

FILES
- index.html : website content
- style.css  : design and responsive layout
- script.js  : mobile menu and footer year

HOW TO RUN ON A PHONE (ACODE)
1. Extract this ZIP file.
2. Open the extracted Sangavi_Portfolio_Website folder in Acode.
3. Open index.html.
4. Tap Preview (or the play/preview option) to view the website.
5. Keep all three files in the same folder.

HOW TO RUN ON A LAPTOP
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser (or use Live Server).
